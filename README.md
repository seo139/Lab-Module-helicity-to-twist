# From DNA Helicity to Structural Twist: An Undergraduate Laboratory Module for DNA Origami Design

This repository contains supporting data and simulation files for a hands-on laboratory module on DNA origami design. The module uses rectangular DNA origami tiles and ribbons to show how DNA helicity and crossover placement affect the shape of assembled structures.
